# Выгрузка встреч календаря (Outlook 2016)

## Установка

1. Скачайте ZIP: Code → Download ZIP
2. Распакуйте в любую папку
3. Запустите `install.bat`
4. Откройте Outlook → **Календарь** → **Выгрузить встречи**

Файлы в комплекте: `install.bat`, `import-macro.vbs`, `olkexplorer.officeUI`, `ExportCalendarMeetings.bas`.

Результат Excel сохраняется в папку **Изображения**.

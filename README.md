# Выгрузка встреч календаря (Outlook 2016)

## Установка

1. Code → Download ZIP → распаковать
2. Запустить `install.bat` (закроет Outlook, поставит кнопку ленты и импортирует макрос)
3. Открыть Outlook

### Повторная установка / обновление (важно)

Если макрос уже стоял раньше (в т.ч. с «кракозябрами» вместо русского текста):

1. Закройте Outlook
2. Снова запустите `install.bat` — он **удаляет** старый модуль `ExportCalendarMeetings` и импортирует новый `.bas`
3. Либо вручную: `Alt+F11` → удалить модуль `ExportCalendarMeetings` → File → Import File → `ExportCalendarMeetings.bas`

Русские подписи в диалогах собраны через `ChrW`, поэтому файл можно хранить как UTF-8 на GitHub — в Outlook текст останется читаемым.

## Как запустить

**Вариант A (всегда работает):** `Alt+F8` → `ExportManagerCalendarMeetings` → Выполнить

**Вариант B (кнопка на вкладке Календарь):**
1. Открыть **Календарь** (не почту)
2. Файл → Параметры → Настроить ленту
3. Справа: **Календарь** → Создать группу
4. Слева: **Макросы** → `ExportManagerCalendarMeetings` → Добавить → ОК

Excel сохраняется в папку **Изображения**.

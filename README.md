# Выгрузка встреч календаря (Outlook 2016)

## Установка

1. Code → Download ZIP → распаковать
2. Запустить `install.bat`
3. Открыть Outlook

## Как запустить

**Вариант A (всегда работает):** `Alt+F8` → `ExportManagerCalendarMeetings` → Выполнить

**Вариант B (кнопка на вкладке Календарь):**
1. Открыть **Календарь** (не почту)
2. Файл → Параметры → Настроить ленту
3. Справа: **Календарь** → Создать группу
4. Слева: **Макросы** → `ExportManagerCalendarMeetings` → Добавить → ОК

Excel сохраняется в папку **Изображения**.

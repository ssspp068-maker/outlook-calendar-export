1. Скачайте ZIP (Code → Download ZIP) и распакуйте.
2. Запустите `install.bat` (закроет Outlook/Office, поставит кнопку; макрос — через OTM или автоимпорт .bas).
3. Откройте Outlook → **Календарь** → «Выгрузить встречи» (или Alt+F8 → `ExportManagerCalendarMeetings`).

Если автоимпорт напишет «Объект не поддерживает…» при уже включённом AccessVBOM: Alt+F11 → Import File → `ExportCalendarMeetings.bas`.

Не запускайте `InstallCalendarExportButton`.
